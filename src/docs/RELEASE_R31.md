# CoC Engine V18.8 R31 发布包

发布日期：2026-10-18

## 本批范围

- 产品号由 18.7.0 升为 18.8.0，修订号 R31，收口 R30.1–R30.5。基线是 `CoC_Engine_V18.7_ParadoxFree_R30_20261016.zip`。
- 存档结构升到第 9 版。V18.7 及更早的存档第一次读入时自动升级，并写回被读出的那份副本。
- 发布文件：`CoC_Engine_V18.8_ParadoxFree_R31_20261018.zip`；SHA-256 记在同目录的 `.sha256` 文件里（打包后生成，不在 ZIP 内）。
- 包内布局：游戏文件在根目录（与以前相同）；新增 `server/`（联机中转服务程序，已带依赖，无需 `npm install`）、
  `启动联机服务.bat` / `.command`、`手机测试说明.md`。

## 内容

| 方面 | 变化 |
|---|---|
| 调查员身份 | 唯一编号，发一次、写进存档；同一次存档的各副本自动同号；不同存档的同名者由玩家确认合并，可拆分；决定随存档保存，按时间先后决出 |
| 按人过滤 | `js/state/visibility.mjs` 三层默认拒绝；AI 密钥与本机界面状态任何人都收不到；地图按人探索 |
| 暗骰 | `roll_dice` / `request_skill_check` 可 `hidden` / `visible_to`；推动沿用原检定；游客视图隐去 AI 叙述的骰子段，只在描述该暗骰的叙述里替换数值 |
| 联机服务程序 | `server/`：守秘人 `http://localhost:8080`；玩家 mkcert https / 自签 https / http 三档与 Tailscale；凭据只存哈希；断线补发；连接自检页 `/__relay/selftest` |

游戏页面尚未接入联机（系统 17、19），手机目前可测连接自检页与单机游戏，见《手机测试说明.md》。

## 验证

- `npm run ci:smoke` 通过（含 `visibility_leak_smoke`、`identity_registry_smoke`）；Playwright 18 项通过；`server` 的 `npm test` 18 项通过。
- 六轮故意改坏共 117 处（投影、身份登记、暗骰、读写回），测试全部抓到；服务程序另 15 处全部抓到。
- 连接自检页在 Chromium 中以守秘人（本机）+ 两部模拟手机（http 档、自签 https 档）实跑通过：加入、收消息、发请求三项全部打钩。
- 四份独立代码审查报告与修订记录在开发仓库的 `docs/architecture/`。

## 已知限制

- AI 在以后的回合里重提早先的暗骰数值，或用中文数字等写法复述，无法从文本判定；第一道防线是提示 AI 不写数值。
- 不同设备时钟不准时，身份决定的"较晚者"按各自时钟判断。
- 群体检定、对抗检定与理智 / 战斗 / 追逐检定尚不能暗骰。
- 真实手机与 Tailscale 实测待完成。
