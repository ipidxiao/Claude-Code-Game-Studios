## 查错思路

### 一、按旧 BUG 的类型回扫，而不是只修点名的那一处

先通读 `js/data/dev_logs.mjs` 的 114 条记录，把历史上修过的问题归成类型，再对每一类扫全部代码：

| 类型 | 日志里的先例 | 本次在别处找到的同类 |
|---|---|---|
| 外部请求 | R29.57 入口去掉 CDN | pdf_import 仍回退 cdnjs；AI 接口地址不校验协议 |
| 点名回落 | R29 未知名字不得落到活跃者 | 剧本效果 pickTarget 仍回落 |
| 字段白名单 | R22 选项分支被白名单丢掉 | useSeedClueQuality 被丢 |
| 切模清理 | R7–R17 多次补漏 | 关键线索路径、受阻计数、上一次检定未清 |
| 存档往返 | R1 / R15 / R24 漏存 | 读档时余波骰盘被冲掉 |
| 工具回滚 | R24 补 scenarioRunner 等 | 时钟副本、KP 状态、标记、热度等未回滚 |
| 工具参数 | R29 死别名对齐 | 3 个功能参数与 12 个别名被严格校验拒绝 |
| 剧本断链 | R29.58 侧房、封门 | 孪生包停在修复之前；包对等脚本把门槛盖错选项 |
| 预缓存鬼影 | V18.4 icon-180 | index.html 仍引用 icon-180.png |

### 二、先写扫描器，并先证明扫描器能报错

对每一类写一个可重复运行的扫描器（导入导出、选项键、剧本图、参数对账），先用故意写错的小夹具确认它能报出问题，再拿去扫真实代码。扫描结果为 0 时，才有资格说这一类是干净的。

### 三、读代码查不到的，就把引擎跑起来压

- **工具模糊测试**：66 个工具各数百次调用，只喂通过 `validateToolArguments` 的参数（AI 能真正送达的输入）；每次调用后模拟玩家点骰盘，覆盖 16 种检定；检查异常、NaN、负数、HP 镜像分裂、返回文本中的 undefined，以及点不掉的骰盘。共约 4 万次调用。
- **剧本遍历**：用真实运行器、真实引擎随机走全部 18 本内置剧本，每本数十局，记录卡死（无选项又未结束）、软锁（选项全被门槛挡住）、异常、垃圾文本和结局覆盖。

### 四、先证伪，再修

每个疑点先确认是不是测法造成的：

- 剧本交锋显示 undefined：遍历器少传了点数，真实界面会传，不修。
- 沿海祭典撞步数上限：静态检查确认没有陷阱区，只是随机游走在大地图里兜圈，不修。
- 夜班门槛一度被判为软锁：它的节点效果本身就满足门槛，撤回改动；真正的问题是证据档写死，另行修复。

### 五、先红后绿，门禁防整类回潮

每个修复先写测试，在旧代码上确认会失败，再修到通过。门禁尽量写成整类规则，例如：

- 任何 `js/**` 模块不得出现 CDN 域名
- 处理器读取的每个参数都必须在 schema 中声明
- 剧本数据里出现的每个选项键都必须过映射
- 全量导出的孪生包，跳转必须与 ESM 一致
- 出口全带门槛的节点，必须由自身效果满足其中一个
- 每个内置剧本节点的正文只能显示一次

## 改动摘要

### 联网与安全
- pdf_import 去掉 cdnjs 回退，加载失败可重试。
- AI 接口地址只允许 https，http 仅限本机；不合规时不发送密钥、不重试。

### 剧本
- 散文桥不再把已内联的正文再拼一遍：8 本长篇的 403 个节点曾全部显示两遍。
- 落到检定节点且没有挂起检定时，自动出该节点的骰盘：28 条侧房选项与列车终章曾卡死。结算时不重放正文、不重复执行效果。
- 疗养院日记、失踪儿童井边补无门槛退路。
- 灯塔夜班：判读日志掷图书馆使用，日志证据档随检定变化，三个结局都能走到。
- useSeedClueQuality 不再被选项白名单丢掉；剧本效果点名不存在的人时报错。
- 假面嘉年华失败文本中 3 处 undefined 修正。
- 教程、沿海祭典、假面嘉年华、失踪儿童、无尽列车的旧版 JSON 删除；疗养院、小巷追逐、灯塔夜班孪生包同步。包对等脚本按 id 认门槛，补缺时复制原选项。

### 状态、存档与回滚
- 切模清空 kpEngine.scenePaths、keyClueBlockedAttempts 与 lastSkillCheck。
- 读档后再把余波转成检定，骰盘不再被聊天重建冲掉。
- 工具回滚移到 `js/ai/tool_snapshot.mjs`，覆盖处理器可能写入的全部运行状态。

### 工具与规则
- 变形术的生物外形、近战情境、开火只打一发、12 个别名加入 schema；enemy_name 说明改为 R29.64 规则。
- 骰式 1D0、0D6 不再出 NaN 或多掷；单个骰式最多 100 颗、1000 面。
- 奖励骰与惩罚骰先抵消、再封顶 ±2。
- 精神病院单次最多结算 24 个月。
