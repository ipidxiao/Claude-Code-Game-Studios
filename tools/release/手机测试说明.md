# CoC Engine V18.8 R31.4 手机测试说明

> **先确认解压的是哪一版**：根目录的 `版本信息.txt` 写着发布包名和提交号，文件夹名末尾也带提交号。
> 没有 `版本信息.txt`、或根目录没有 `一键准备并启动.bat` 的，是旧的 R31 包，请换用新包解压到新文件夹。

这一版的联机只到"服务程序 + 连接自检"：游戏页面里还没有开房间 / 加入房间（后续版本做）。
手机上能测的是两件事：**① 手机能不能连上你电脑上的服务程序（三种连接方式 + Tailscale）；② 手机能不能打开并运行游戏本身。**
测完把每一步的结果和截图发给我，ADR-0001 就靠这次实测转为"已接受"。

## 最省事：一键准备（Windows）

解压后双击根目录的 **`一键准备并启动.bat`**，弹出"是否允许更改"时点**是**。它会依次：
检查并（用 winget）安装 Node.js → 结束占用 8080 / 8081 / 8443 的旧 python 窗口 → 放行防火墙 8081、8443 端口 →
安装 OpenSSL（开 https 档）→ 启动服务程序 → 在浏览器打开连接自检页。Tailscale 是可选的，脚本不会安装它。看到绿色的"准备完成"后，直接从下面的**第三步**开始。
如果它提示没能自动安装 Node.js，按提示从官网装好后再双击一次。下面"准备"与第一、二步是手动做法，一键准备成功就可以跳过。

## 准备（只做一次）

1. 电脑装 **Node.js 20 或更高版本**（https://nodejs.org ，选 LTS）。装完在命令行输入 `node -v` 能看到版本号即可。
2. 想测 https 档（B 档）：电脑上要有 OpenSSL。一键准备脚本会用 winget 自动安装；手动装 **Git for Windows** 也自带。没有也不要紧，http 档照样能测。
3. 把这个压缩包解压到 `D:\CoC_Engine_Releases\`（压缩包里自带一层同名文件夹，解压时选"解压到当前文件夹"即可，不要再套一层）。
4. **关掉以前用的 `python -m http.server 8080` 窗口**（否则 8080 端口被占用）。

## 第一步：启动服务程序

- Windows：双击根目录的 **`启动联机服务.bat`**。
- macOS：双击 `启动联机服务.command`（第一次若被拦，右键 → 打开）。

窗口里会打印：

```
守秘人（本机）：http://localhost:8080
连接自检（在本机打开，开房间后把链接发给手机）：http://localhost:8080/__relay/selftest
玩家 https（B 档 …）：https://192.168.x.x:8443
玩家 http（C 档）：http://192.168.x.x:8081
```

Windows 第一次会弹防火墙提示：**勾选"专用网络"和"公用网络"，点允许**（用电脑开热点时，网络常被识别为公用）。
这个窗口在测试期间不要关。

## 第二步：电脑上确认游戏照常

电脑浏览器打开 `http://localhost:8080`：游戏大厅出现，**以前的存档和 AI 设置都还在**（地址和以前一样）。

## 第三步：电脑开房间

电脑浏览器再开一个标签：`http://localhost:8080/__relay/selftest` → 点 **开房间**。
页面会列出给手机用的链接（每个地址有 https 和 http 两种）。点"复制"，用微信 / QQ 的"文件传输助手"发到手机。

## 第四步：手机连接（逐档测试）

手机和电脑要在同一个网络里：连同一个 Wi-Fi，或者电脑开热点手机连上，或者手机开热点电脑连上。

| 档位 | 打开哪个链接 | 会遇到什么 |
|---|---|---|
| C 档 http | `http://…:8081/__relay/selftest?invite=…` | 直接打开 |
| B 档 https | `https://…:8443/__relay/selftest?invite=…` | 提示"不安全 / 证书无效"：iPhone Safari 点"显示详细信息 → 访问此网站"；安卓 Chrome 点"高级 → 继续前往" |

手机页面上应该看到：

1. **加入房间 ✓**
2. 在电脑自检页点 **给所有玩家发测试消息** → 手机出现 **收到守秘人的测试消息 ✓**
3. 手机点 **发请求给守秘人** → 手机出现 **守秘人收到你的请求 ✓**，电脑"记录"里也出现这条请求

两种链接各测一遍，**每次截一张手机全屏图**。"这台设备"一栏里 http 档显示"安全上下文 ✗、离线缓存 ✗"是正常的，不影响联机。

## 第五步：手机打开游戏

手机浏览器打开 `http://<电脑地址>:8081/`（和自检链接同一个地址，去掉后面的 `/__relay/...`）：
游戏大厅应正常显示。想试单机：手机上进入设置填写 AI 密钥即可（手机的存档与电脑分开保存）。截一张大厅图。

R31.4 这一版请重点看：

1. **本地剧本「哈特利老宅」**：点「行动」选「环顾门厅」→ 应先出现「掷骰：【侦查】」按钮，掷完才有下文；失败时是一段「没看出来」的剧情，随后选项照常。「进入客厅」这类走动不掷骰。
2. **在线守秘人**（填好 AI 密钥后切换在线 AI）：回复应是小说正文，对话单独成段；末尾不再有「ACTION_ORDER」「A1/B2」或英文；可选行动出现在「行动」菜单里，是一句句动作。
3. 顶部守秘人状态栏写「平静」而不是「CALM」。

## 第六步（可选，作者已决定不作为必测项）：Tailscale 外网测试

1. 电脑和手机都装 Tailscale（https://tailscale.com/download ），登录同一个账号。
2. 手机关掉 Wi-Fi，只用流量。
3. 电脑重启服务程序后，刷新自检页：链接列表里会多出 **Tailscale**（100.x.x.x）的地址，用它测一遍第四步。
4. 想要不报证书警告的 https：电脑命令行运行 `tailscale serve --bg http://localhost:8081`，按提示开启后会给出
   `https://<电脑名>.<你的网络名>.ts.net` 地址，手机打开 `https://<那个地址>/__relay/selftest?invite=<同一个邀请码>`。

## 测完发我

- 每一档：链接能否打开、三项是否打钩、手机全屏截图
- 手机型号与浏览器（例如 iPhone 15 Safari、小米 14 Chrome）
- 第五步大厅截图；R31.4 的三项各一张截图（掷骰按钮、失败剧情、在线守秘人回复）
- 卡住的地方：截图 + 服务程序窗口最后几行

## 其他

- 结束测试：关掉服务程序窗口即可。以后单机游玩仍可用原来的 `python -m http.server 8080`。
- 房间信息存在 `server/data/room.json`（只存哈希），重启服务程序后房间和链接仍有效；想作废全部链接，在电脑自检页点"关闭房间"。
- 端口被占用：关掉占用 8080 / 8081 / 8443 的程序（通常是旧的 python 窗口）。
