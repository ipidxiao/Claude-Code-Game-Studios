# CoC Engine V18.6 R29.26 存档诊断

发布日期：2026-10-04

## 行为

- `diagnoseSaves()` 只读当前模组的 `auto/slot1/slot2/slot3`。
- 每条记录包含 local 与 IndexedDB 的存在、合法性、`savedAt`、地点，以及当前选中的副本。
- 导出报告不包含存档正文。
- 修复缺失副本时，把选中副本的原始文本写入另一侧。
- 两份都有效但 `savedAt` 不同，默认拒绝覆盖；只有显式确认后才覆盖，并备份被覆盖的原文。
- 清理只删除损坏副本，且另一份必须有效。
- 未确认的修复和清理不会写存储。

## 安全边界

- 不提升 `SAVE_SCHEMA_VERSION`，不把内存迁移结果写回磁盘。
- 备份键为 `coc_diag_backup_<时间戳>`，与正式槽位键分开。
- 备份写入失败时，修复和清理都会中止。
